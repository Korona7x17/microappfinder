## Key Decisions

### D-2025-10-04-01 — Reddit API Data Retention Policy
Rationale: Reddit ToS requires deletion of user content when removed from platform; 48h cache + daily sync ensures compliance while supporting feature requirements
Status: Accepted | Date: 2025-10-04 | Ref: specs/001-reddit-pain-point/research.md
Details: Raw Reddit content (text, URLs, author) cached 48h max in Redis with TTL, derived aggregates (topics, scores, PainPoint.extracted_text) stored indefinitely in PostgreSQL as non-user-content, daily deletion sync job checks Reddit API and purges deleted posts

### D-2025-10-04-02 — Composite Scoring Algorithm
Rationale: Balances multiple signals (popularity, engagement, freshness, pain intensity) for better opportunity ranking than single-metric approaches
Status: Accepted | Date: 2025-10-04 | Ref: specs/001-reddit-pain-point/research.md
Formula: score = 0.3×upvotes_norm + 0.25×comments_norm + 0.25×recency_norm + 0.2×sentiment_polarity

### D-2025-10-04-03 — User-Level Privacy Enforcement
Rationale: Prevents data leaks and aligns with constitution principle of data privacy; dual-layer enforcement (DB + API) provides defense in depth
Status: Accepted | Date: 2025-10-04 | Ref: specs/001-reddit-pain-point/plan.md
Details: Database-level user_id foreign keys + API middleware ownership checks (search_run.user_id == current_user.id) before allowing access
