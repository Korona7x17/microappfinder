## Key Decisions

### D-2025-10-05-01 — Worker Environment Variable Strategy
Rationale: Worker runs from apps/worker/ directory and cannot access apps/api/.env file. Explicit env vars passed at runtime ensure PRAW can authenticate with Reddit API.
Status: Accepted | Date: 2025-10-05
Details: REDDIT_CLIENT_ID, REDDIT_CLIENT_SECRET, REDDIT_USER_AGENT must be passed as environment variables when starting worker. Alternative approaches (python-dotenv loading from ../api/.env or copying .env) rejected for clarity.

### D-2025-10-05-02 — Deferred Clustering Pipeline
Rationale: MVP delivers functional pain point extraction; clustering/brief generation adds significant complexity (embeddings, LLM calls, scoring) better suited for separate feature
Status: Deferred | Date: 2025-10-05
Details: Current system shows 170 raw pain point extractions. Future feature will: (1) cluster by semantic similarity, (2) score clusters by market opportunity, (3) generate top 3-5 micro-app briefs with LLM. Database schema already supports this (clusters, briefs tables exist).
