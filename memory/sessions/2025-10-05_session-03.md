## Key Decisions

### D-2025-10-05-03 — Algolia HN API Choice
Rationale: Official Algolia HN API has no rate limits, is free, and includes Ask HN filtering. Eliminates need for credentials and complex rate limiting.
Status: Accepted | Date: 2025-10-05
Details: Using https://hn.algolia.com/api/v1/search with tags="ask_hn" and min_points=10 threshold. No authentication required. Circuit breaker added for resilience despite no expected rate limits.

### D-2025-10-05-04 — Deduplication Strategy
Rationale: URL-based exact match (after normalization) for Phase 1, semantic similarity (85% Jaccard) for Phase 2. Keeps higher engagement item as primary, preserves both source IDs.
Status: Accepted | Date: 2025-10-05
Details: URL normalization strips utm_*, protocol (http/https), www prefix, trailing slashes. Title similarity uses Jaccard index on tokenized titles after removing "Ask HN:", "Ask Reddit:" prefixes. Threshold of 0.85 balances precision/recall.

### D-2025-10-05-05 — RQ Job Chaining
Rationale: Unified aggregation must wait for both Reddit and HN jobs to complete. RQ's depends_on=[job1, job2] ensures sequential execution only after parallel sources finish.
Status: Accepted | Date: 2025-10-05
Details: Enqueue order: (1) reddit_job, (2) hn_job (parallel), (3) unified_job (depends_on=[reddit_job, hn_job]). Worker processes reddit and hn simultaneously, then runs unified aggregation with full dataset.

### D-2025-10-05-06 — Circuit Breaker Configuration
Rationale: Even with no expected rate limits, circuit breaker prevents cascade failures if Algolia experiences downtime. 3 failures → open circuit, 2min timeout, 2 successes → close.
Status: Accepted | Date: 2025-10-05
Details: Graceful degradation: when circuit is OPEN, HN service returns empty array instead of throwing exception. Search completes with Reddit-only results. Circuit auto-recovers via HALF_OPEN state after timeout.

### D-2025-10-05-07 — 48h Cache Pattern Consistency
Rationale: Mirroring RedditPost 48h TTL for compliance consistency. HackerNewsItem uses same expires_at + is_expired pattern. Daily cleanup at 3AM (after Reddit sync at 2AM).
Status: Accepted | Date: 2025-10-05
Details: Both Reddit and HN content cached for 48 hours. HackerNews has no deletion compliance requirements (unlike Reddit ToS), but cache pattern maintained for architectural consistency and resource management.

## Technical Implementation

### Composite Scoring Formula (Unchanged)
```
score = 0.3 × normalize(upvotes) +
        0.25 × normalize(comments) +
        0.25 × recency_decay +
        0.2 × normalize(sentiment)
```
- Log-scale normalization: `log(n+1) / log(max)` for upvotes (max ~1000) and comments (max ~500)
- Recency decay: `exp(-age_days / 30)` with 30-day half-life
- Sentiment: TextBlob polarity normalized from [-1,1] to [0,1]

### Deduplication Pipeline
1. Load Reddit posts (48h cache, unexpired)
2. Load HN items (48h cache, unexpired)
3. For each Reddit post, check all HN items:
   - URL match (after normalization) → duplicate
   - Title similarity >= 0.85 → duplicate
4. Merge duplicates: keep higher engagement, preserve both IDs in source_post_ids
5. Return unique_items + duplicates list

### Worker Job Flow
```
POST /api/reddit/search
  ↓
Create SearchRun (sources_queried=["reddit", "hackernews"])
  ↓
Enqueue: reddit_job (parallel) ──┐
Enqueue: hn_job (parallel) ──────┤
                                 ↓
                    Enqueue: unified_job (depends_on=[reddit, hn])
                                 ↓
                    Dedup → Rank → Extract pain points with source_platform
```
